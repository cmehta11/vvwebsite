## 🚀 How to Deploy

### **Option 1: Deploy to Netlify/Vercel (Recommended)**
1. Upload all project files to GitHub repository
2. Connect repo to Netlify or Vercel
3. Set build settings:
   - Build command: (none - static site)
   - Publish directory: `/`
4. Deploy - site will be live in minutes
5. Add custom domain (e.g., `www.vertvista.com`)

### **Option 2: Traditional Web Hosting**
1. Upload all files via FTP to web server
2. Ensure `index.html` is in root directory
3. Verify all relative links work (`/css/`, `/js/`, `/images/`)
4. Test contact form integration
5. Submit `sitemap.xml` to Google Search Console

### **Option 3: Use the Publish Tab (Easiest)**
1. Go to the **Publish** tab in your development environment
2. Click "Publish Project"
3. Get instant live URL
4. Optionally connect custom domain

## 🛠️ Development Workflow

### **For Adding New Blog Posts:**
1. Use `templates/blog-post-template.json` as starting point
2. Write 1,200-1,800 words of original content
3. Add Article schema with author, date published
4. Include internal links to 3-5 related pages
5. Add to `blog.html` grid
6. Update `sitemap.xml` with new URL
7. Test on mobile devices

### **For Adding New Location Pages:**
1. Use `templates/location-page-template.json`
2. Research city demographics, major business districts
3. Update LocalBusiness schema with accurate coordinates
4. List 5-8 specific "Areas We Serve" (with landmarks)
5. Add city-specific testimonials if available
6. Update navigation "Locations" dropdown on ALL pages
7. Add to `sitemap.xml`

### **For Updating Navigation:**
1. Copy navigation code from `index.html` (lines 20-70)
2. Paste into target page's `<nav>` section
3. Verify dropdown menus work (Services, Resources, Locations)
4. Test responsive mobile menu toggle
5. Check all links point to correct pages
