## 🎯 OPTIMIZATION PARAMETERS USED

### **CDN Image Optimization:**
- `?w=1920&q=85` - Hero images (1920px width, 85% quality)
- `?w=1200&q=85` - Gallery images (1200px width, 85% quality)
- `loading="lazy"` - Lazy loading (load images when scrolled into view)

### **Why These Settings:**
- **Width 1200px**: Perfect balance for quality and file size
- **Width 1920px**: Full HD for hero backgrounds
- **Quality 85%**: Sweet spot - looks perfect, saves 40-60% file size
- **Lazy loading**: Only loads images when user scrolls to them

## 🔧 ADDITIONAL OPTIMIZATIONS INCLUDED

### **1. Lazy Loading Attribute**
```html

```
- Images load only when scrolled into view
- Saves bandwidth and speeds up initial page load
- Supported by all modern browsers

### **2. Progressive JPEG**
- Images load incrementally (blur to sharp)
- Users see something immediately
- Better perceived performance

- Good for SEO and accessibility
