Based on the Vertvista PDFs, your images should include:

**HERO IMAGES:**
- Modern office spaces with plants

- Biophilic office environments

**SERVICE IMAGES:**

## 📝 IMAGE SPECIFICATIONS

### **Recommended Image Sizes:**

**Hero Image:**
- Size: 1920x1080px (Full HD)
- Format: JPG or WebP
- Max file size: 500KB (compressed)

**Service Cards:**
- Size: 800x600px
- Format: JPG or WebP
- Max file size: 200KB

**Gallery Images:**
- Size: 1200x800px
- Format: JPG or WebP
- Max file size: 300KB

**Planter Product Images:**
- Size: 800x800px (square)
- Format: JPG or WebP with transparent background where appropriate
- Max file size: 150KB

**Client Logos:**
- Size: 300x150px (maintain aspect ratio)
- Format: PNG with transparent background
- Max file size: 50KB

**Team/Testimonial Photos:**
- Size: 400x400px (square)
- Format: JPG
- Max file size: 100KB

## 🎨 IMAGE OPTIMIZATION TIPS

Before adding images to website:

1. **Compress Images**: Use tools like TinyPNG, ImageOptim, or Squoosh
2. **Convert to WebP**: Modern format, better compression
3. **Resize Appropriately**: Don't use 4000px images for 400px displays
4. **Add Alt Text**: Descriptive text for SEO and accessibility
5. **Use Lazy Loading**: Images load as user scrolls
