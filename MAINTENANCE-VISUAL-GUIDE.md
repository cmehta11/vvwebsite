## Interactive Elements

### Hover Effects
- **Cards:** Lift up 5px + shadow increase
- **Buttons:** Background color swap + lift
- **Table Rows:** Light gray background
- **Images:** Shadow increase

### Smooth Scrolling
- "Get Quote" buttons → #quote-form
- All anchor links
- Back to top button

### Form Validation
- Real-time email format check
- 10-digit phone number validation
- Required field indicators (red asterisks)
- Focus state: Lime green border

## Mobile Transformations

### Desktop → Mobile Changes
1. **Hero Stats:** 4 columns → 2 columns
2. **Benefits Grid:** 4 columns → 1 column
3. **Pricing Table:** Full width → Horizontal scroll
4. **Service Details:** 3 columns → 1 column
5. **Coverage Cards:** 3 columns → 1 column
6. **Gallery:** 3 columns → 1 column
7. **Form:** 2 columns → 1 column
8. **FAQ Grid:** 2 columns → 1 column

### Mobile-Specific Features
- Hamburger menu (☰)
- Larger tap targets (48px minimum)
- Swipeable pricing table
- Simplified spacing
- Sticky header on scroll

## Key Visual Principles

### Hierarchy
1. **Primary:** Pricing table (largest, central)
2. **Secondary:** Service details, coverage map
3. **Tertiary:** Gallery, FAQs
4. **CTA:** Quote form (high contrast, centered)

### Consistency
- All card shadows match
- Icons use same style (Font Awesome)
- Border radius: 12px standard
- Padding: 30px for cards
- Gaps: 30px between elements

### Whitespace
- Section padding: 80px top/bottom
- Container max-width: 1200px
- Card spacing: 30px gap
- Generous line-height: 1.6

### Typography Scale
- H1 (Hero): 48px bold
- H2 (Section): 36px semibold
- H3 (Card): 20-24px semibold
- Body: 16px regular
- Small: 14px regular

## Accessibility Features

✓ Alt text on all images  
✓ ARIA labels on buttons  
✓ Form labels properly associated  
✓ Focus indicators visible  
✓ Color contrast WCAG AA compliant  
✓ Keyboard navigation supported

- **Images:** Lazy loaded with CDN optimization
- **CSS:** Separate file for modular loading
- **JS:** Uses existing script.js (no additional weight)
- **Fonts:** Google Fonts preconnected
- **Icons:** Font Awesome CDN cached
