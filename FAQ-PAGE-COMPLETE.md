## 🔧 JavaScript Functionality

### Core Functions:

1. **`accordionToggle()`**
   - Opens/closes FAQ items
   - Closes other items in same category
   - Adds/removes 'active' class

2. **`categoryFilter()`**
   - Filters FAQs by category
   - Shows/hides categories
   - Updates button active states

3. **`searchFAQs()`**
   - Real-time search as user types
   - Matches question and answer text
   - Shows/hides matching items
   - Displays no results message

4. **`smoothScroll()`**
   - Handles anchor link clicks
   - Accounts for fixed navbar height
   - Smooth scrolling animation

5. **`keyboardNavigation()`**
   - Arrow keys navigate questions
   - Enter/Space toggle accordion
   - Accessibility compliant

6. **`hashHandling()`**
   - Opens specific question from URL hash
   - Scrolls to target on page load
   - Enables deep linking

## 🎨 How to Customize

### Add a New Question:
```html
<div class="faq-item">
    <button class="faq-question">
        <span>Your question here?</span>
        <i class="fas fa-chevron-down"></i>
    </button>
    <div class="faq-answer">
        <p>Your answer here.</p>
        <ul>
            <li>Bullet point if needed</li>
        </ul>
    </div>
</div>
```

### Add a New Category:
```html
<div class="faq-category" data-category="yourcategory">
    <h2 class="category-title">
        <i class="fas fa-icon"></i> Your Category Name
    </h2>
    <div class="faq-accordion">
        <!-- FAQ items here -->
    </div>
</div>
```

Then add filter button:
```html
<button class="category-btn" data-category="yourcategory">
    <i class="fas fa-icon"></i> Your Category
</button>
```
